    Avisos no WhatsApp

    O robô avisa no WhatsApp um dia antes e uma hora antes de cada atendimento. Use os botões abaixo para testar como a mensagem chega.

    Passo a passo:
    1) Abra o WhatsApp e encontre a mensagem “CallMeBot API Activated” enviada para o seu número.
    2) Copie o número do apikey (o seu é o mesmo do secret do GitHub).
    3) Cole acima e toque em Salvar neste navegador.
    4) Toque em um dos botões de teste.

    O site não consegue ler os secrets do GitHub (eles ficam privados e valem só para o robô). Por isso a apikey precisa ser digitada aqui uma vez — ela fica salva apenas neste navegador.
